GitHub+Cloudflare+Hexo 个人网站搭建踩坑回顾

Pi Ruiyong Lv2
  2026-04-15 11:27:20 2026-04-15 11:27:20 Created   2026-04-23 11:01:11 2026-04-23 11:01:11 Updated  
  • Pi 
 

引言

作为一个”零”代码基础的小白，搭建个人博客的主要目的是记录一下踩过的那些坑和个人所思所想。(当然不会是为了把域名用起来包的这盘饺子🥟)

使用GitHub+Cloudflare+Hexo 这个组合完全是因为便宜，除了域名之外完全免费，无需购买VPS或服务器，GitHub提供免费托管，Cloudflare提供免费CDN和DNS(CF真是赛博活菩萨！)

除此之外还有一些别的优势，比如: 全球加速(Cloudflare全球275+节点CDN加速)，安全可靠(Cloudflare提供DDoS防护、WAF、HTTPS加密，GitHub提供版本控制和代码安全)，高度定制化(Hexo有丰富主题(500+)和插件生态，可完全自定义博客外观和功能)，简化工作流(Markdown写作→本地预览→Git提交→自动部署)等等…

如今借助AI工具这套方案可以快捷方便的搭建起来，现在也算是马马虎虎搭建起来了，简单记录一下踩过的坑吧。

准备工作

  • 一台电脑: MacBook Pro 2016款，系统12.7.6 Monterey，intel芯片
  • 一个Github账号: 代码托管
  • 一个Cloudflare账号(可以用Github账号登录): CDN、DNS、DDoS、HTTPS相关服务
  • 一个炫酷的域名(这是核心👻): 可以从阿里云上购买

  1. Cloudflare R2媒体文件存储
  • 登录 Cloudflare，左侧「R2」→「创建存储桶」，命名（比如 blog-bucket）
  • 进入存储桶→「设置」→「公共访问」→开启「公共访问」，保存
    这里需要订阅免费计划，但是需要绑定一张信用卡。在咸鱼上5块钱找一个就行。

阿里云域名 + Cloudflare 解析（绑定域名）

  1. 把阿里云域名托管到 Cloudflare
  • 打开 Cloudflare → 点添加站点 → 输入qwer1234.com → 选免费计划
  • Cloudflare 会扫描现有 DNS 记录（不用改），点继续
  • 复制 Cloudflare 给的两个名称服务器（如xxx.ns.cloudflare.com）
  • 登录阿里云域名控制台 → 找到qwer1234.com → 点管理 → DNS 修改
  • 删除原来的 DNS，粘贴 Cloudflare 的两个名称服务器 → 保存
  • 等待生效（通常 10 分钟 - 48 小时，耐心等！）
  1. 配置域名解析
  • 回到 Cloudflare→网站→qwer1234.com→「DNS」→「记录」
  • 添加 1 条 CNAME 记录：
  • 开启代理（橙色云朵），等待 5-10 分钟
  • 打开 GitHub 仓库→Settings→Pages→「Custom domain」输入 qwer1234.com，勾选「Enforce HTTPS」
  1. 绑定域名到 Workers 服务
    进入左侧Workers和Pages，进你建的workers，然后点设置，自定义域，把你的域名加进去。
  2. 最终验证
    浏览器访问 https://你的域名，能看到博客页面，说明域名绑定成功。
